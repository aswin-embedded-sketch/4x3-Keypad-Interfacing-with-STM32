# 4×3 Keypad Interfacing using STM32

## Overview

This project demonstrates interfacing a 4×3 matrix keypad with the STM32F446RE microcontroller.

The keypad consists of four rows and three columns, providing 12 keys for user input. The STM32 scans the rows and columns to detect which key is pressed.

This project helps in understanding GPIO input/output configuration, matrix keypad scanning, and user input handling using STM32.

---

## Components Used

- STM32F446RE Nucleo Board
- 4×3 Matrix Keypad
- Jumper Wires
- Breadboard

---

## Features

- Interfaces a 4×3 matrix keypad with STM32
- Detects key presses
- Uses GPIO pins for row and column scanning
- Supports 12 keypad buttons
- Demonstrates matrix keypad scanning
- Can be used for password and menu-based applications
- Simulated using Proteus

---

## Software Used

- STM32CubeIDE
- STM32CubeMX
- Proteus Professional
- C Programming Language
